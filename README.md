# life-exepectancy-analysis
Predicting global life expectency using Power BI.

Overview

This project analyzes global life expectancy trends using historical data and predicts future values through 2050. The goal is to understand how life expectancy has changed over time and identify long-term patterns.

Research Question

How will global life expectancy change over time, and what trends can be used to predict future values up to 2050?

Tools Used
Power BI
Time-series forecasting
Data visualization techniques
Dataset
Source: World Bank World Development Indicators
Indicator: Life expectancy at birth (years)
Time range: 1960 – present
Methodology
Cleaned and structured data into a time-series format
Used Power BI to analyze trends over time
Applied built-in forecasting (exponential smoothing) to predict future values
Compared trends across decades to identify changes in growth patterns
Visualizations
Line chart showing life expectancy trends over time
Forecasting model projecting values to 2050 with confidence intervals
KPI cards highlighting key metrics (current and predicted values)
Decade comparison to analyze growth trends
Key Insights (To Be Completed)
Life expectancy has steadily increased over time
Growth rates vary across different time periods
Forecast suggests continued increase, but at a changing rate
